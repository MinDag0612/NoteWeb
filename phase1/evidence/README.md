# Phase 1 Evidence Guide

This directory is reserved for real screenshots, exported PDFs, or markdown files containing links that prove compliance with the Git workflow requirements of the midterm project.

## Important Rule

Do not fabricate evidence. Every screenshot or link stored here must be captured from the actual repository hosting platform after the team completes the corresponding action.

## Recommended Evidence Items

Store screenshots or links for the following items:

1. Branch protection settings for the `main` branch
2. Pull request list showing PR-only merges
3. At least one representative pull request with reviewer approval
4. Contributor history showing meaningful contributions from all team members
5. Repository structure overview after Phase 1 cleanup
6. Optional: branch naming examples, review comments, or merge history

Use `EVIDENCE_CHECKLIST.md` in this directory to track completion status.

## Suggested File Names

- `branch-protection-main.png`
- `pull-requests-overview.png`
- `representative-pr-review.png`
- `contributors.png`
- `repository-structure.png`

## Suggested Link Inventory

If screenshots are not convenient, create a markdown file in this directory with links to:

- the repository settings page that shows branch protection
- the pull request list
- one or more reviewed PRs
- the contributors or insights page
